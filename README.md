# Telangana Tourism Analytics and Visualization

A B.Tech Data Analysis and Visualization project exploring Telangana tourism data for 2024–2025. The repository contains the source dataset, reproducible Python cleaning and analysis scripts, generated visualizations, notebooks, and an interactive web dashboard with a map.

## Project structure

- `telangana_tourism_2024_2025.csv` — source dataset used by the Python workflow.
- `data_cleaning.py` — removes duplicate rows, standardizes column names and types, and writes a cleaned CSV.
- `clean_dataset/` — generated cleaned dataset.
- `Data_analysis.py` — creates visitor, district, monthly and tourism-category summary tables.
- `analysis_outputs/` — generated CSV summary tables.
- `Data_visualisation.py` — creates charts from the analysis outputs.
- `charts/` — existing project charts.
- `charts_generated/` — charts generated by the Python workflow.
- `backend/` and `public/` — interactive Node.js dashboard and frontend.
- `Telangana_Tourism_Analysis_Complete_with_Outputs.ipynb` and `Telangana_Tourism_Complete_Data_Analysis_Colab.ipynb` — notebook-based analysis work.
- `Telangana_Tourism_Analysis_Phase_1 (2).pdf` — project proposal.

## Run the Python workflow

Use Python 3.10 or later. From the repository root:

```bash
python -m pip install -r requirements.txt
python data_cleaning.py
python Data_analysis.py
python Data_visualisation.py
```

The scripts create the output folders automatically. Missing source values are retained where possible; the cleaning script does not silently replace missing visitor counts with zero.

## Run the interactive dashboard

The dashboard uses Node.js built-in modules and does not require an npm package installation:

```bash
cd backend
node server.js
```

Open http://localhost:3000 in your browser. The interactive map requires a valid Geoapify API key configured locally in `public/js/config.js`. Do not commit private API keys or passwords to GitHub.
